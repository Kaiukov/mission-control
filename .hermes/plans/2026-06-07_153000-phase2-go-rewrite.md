# Mission Control — Go rewrite from Meow patterns

> **Status:** Phase 2 start  
> **Goal:** Replace bash scripts with a single Go binary.  
> **Adapter:** opencode-go/deepseek-v4-flash (test orchestrator + worker)

## Minimum viable features

```
mc pull          → GitHub Issues → tasks.json
mc run <N>       → spawn Codex in tmux for issue N
mc tui           → terminal dashboard (bubbletea)
mc status        → show running workers
```

## Architecture (from Meow patterns)

```
cmd/mc/main.go              ← cobra CLI entry point
internal/
  adapter/config.go         ← TOML adapter loader
  adapter/opencode.toml     ← opencode-go adapter config
  worker/spawn.go           ← spawn Codex in tmux session
  github/pull.go            ← gh CLI wrapper for issues
  tui/app.go                ← bubbletea dashboard
  tui/model.go              ← TUI state
  tui/update.go             ← key handlers
  tui/view.go               ← render
```

## Why Go (not bash)

- bubbletea TUI works reliably (vs tmux bind-key race conditions)
- Single binary — `go build` → `scp mc hermes:`
- Adapter system from Meow (TOML configs, tested pattern)
- Native concurrency (goroutines for worker monitoring)

## Adapter: opencode-go/deepseek-v4-flash

```toml
# adapters/opencode.toml
[adapter]
name = "opencode-flash"
description = "OpenCode Go with DeepSeek V4 Flash"

[spawn]
command = "codex exec --model opencode-go/deepseek-v4-flash"

[prompt_injection]
method = "literal"
post_keys = ["Enter"]
```
