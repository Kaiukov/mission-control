# WILL — что строим и почему

## 🎯 Цель

Персональный веб-дашборд для управления AI-агентами при разработке. Одно окно где:

- **Задачи** — синхронизация с GitHub Issues
- **Агенты** — Claude Opus оркестрирует, Codex CLI (DeepSeek/GPT mini) пишет код
- **Терминалы** — живые tmux-сессии, видно что делает каждый агент
- **Git** — PR, мерж, деплой — прямо из дашборда

## 🤔 Почему не Termius / cmux

Termius — это просто терминал. cmux — тул для Claude Code. Мне нужно:

- **Не привязан к Claude Code** — Codex, Hermes, OpenCode — любые CLI-агенты
- **GitHub Issues как source of truth** — не надо вводить задачи руками
- **Opus как оркестратор** — раздаёт работу дешёвым моделям, сам не кодит
- **Веб-интерфейс** — смотрю с любого устройства, не нужен SSH

## 🔑 Принципы

1. **Opus думает, дешёвые делают** — оркестратор не пишет код. Экономия 10-15x
2. **Просто** — меньше кода, меньше зависимостей. YAGNI.
3. **Локально** — всё на моём сервере (CT 113), не SaaS
4. **Терминал как сердце** — агенты работают в tmux, как обычно
5. **Состояние в файлах** — не нужно БД кроме SQLite для истории
6. **Веб для наблюдения** — дашборд показываеет статус, не управляет логикой
