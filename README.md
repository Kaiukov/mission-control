# Mission Control — персональный дашборд для AI-агентов

**Цель:** веб-интерфейс для управления задачами, AI-агентами и терминалами. Claude Opus оркестрирует, Codex CLI выполняет.

**Статус:** планирование

## Быстрый старт (когда будет готов)

```bash
cd /root/mission-control
npm run dev          # веб-дашборд на :3000
# Открыть http://192.168.1.131:3000
```
